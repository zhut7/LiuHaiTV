LiuHaiTV —— 便携版使用说明
============================

一、怎么运行
------------
双击本文件夹里的 LiuHaiTV.exe 即可，不需要安装 Python 或任何其他依赖。


二、它是便携的
--------------
程序的所有数据都在本文件夹内，不写系统盘、不写注册表、不改用户配置：

    LiuHaiTV.exe        程序本体
    _internal\          运行库（Qt / Python / 播放内核），勿删
    data\liuhaitv.db    频道库（随包带来一份初始频道表）
    logs\liuhaitv.log   运行日志（按天滚动，保留 10 天）
    logs\crash.log      只有启动出错时才会出现
    使用说明.txt         本文件

想换到另一台电脑：把整个文件夹拷过去就行（U 盘 / 网盘都可以）。
想恢复成出厂的频道表：关掉程序，删掉 data\ 文件夹，下次启动会自动重建。


三、系统要求
------------
- Windows 10 / 11，64 位
- 极少数精简版系统缺少 Microsoft Visual C++ 运行库（2015-2022）时会提示缺 dll，
  装上微软官方的 vc_redist.x64.exe 即可


四、界面速览
------------
左侧是频道列表（中央 / 卫视 两组），点频道即可播放。

底部控制条，从左到右：

    ☰ 频道           收起 / 展开左侧列表
    频道名            当前播放的频道
    📡 源管理         维护当前频道的直播源
    🔄 同步源         从多个公开直播源清单批量更新地址（内置 GitHub 加速）
    ⟳ 刷新源          画面卡住 / 黑屏时点它：断开当前流并重新加载
    音量              默认最大，会记住上次调的值
    ⛶ 全屏           退出全屏按 Esc

在频道上点右键：直播源管理… / 重新检测该频道。
（右键只弹菜单，不会切换频道。）

频道颜色（点过才会判定）：

    灰 = 本次打开还没点过
    橙 = 正在检测
    绿 = 可播放
    红 = 播不了（可以试试「🔄 同步源」换地址）


五、源管理弹窗
--------------
点「📡 源管理」打开，一个频道的所有源都在这里：

    状态列    未检测(灰) / 可播放(绿) / 未通过(红)
    ⤒ 置顶    把这条源排到第一位，优先被尝试
    ▲ ▼       上移 / 下移
    启用勾选   取消勾选的源不参与播放与检测
    测试选中   立刻探一次，把状态刷新出来
    导入 M3U   从本地 M3U 文件批量加源

有个细节值得记住：播放时会**优先选「可播放」状态的源，其次才看优先级**。
所以想让某条源真正先播，先用「测试选中」把它测成绿色。


六、首次使用的建议
------------------
随包的频道库是打包那天从公开清单抓的，可能已经有一部分地址失效。
建议第一次打开后：

1. 点「🔄 同步源」
2. 在弹窗里勾选你想要的来源（默认一个都不勾，需要你自己选）
3. 「新增频道」建议选「央视 + 卫视都补」，这样缺的台会一并补上
4. 点开始同步

它会用上游的最新地址替换掉失效的旧地址，并补上缺的频道。
（你自己手动改过的地址不会被覆盖，只会另外补一条并置顶。）


七、常见问题
------------
1) 双击没反应 / 闪一下就没
   → 打开 logs\crash.log 看看（正常还会同时弹一个错误提示框）。
     把该文件发回来即可定位问题。

2) 杀毒软件报警或者把 exe 删掉了
   → 打包成 exe 的程序常被误报，属正常现象。加入信任 / 白名单即可。

3) 某个台点开是红色的
   → 这个台当前的地址都失效了。点「🔄 同步源」换一批；
     也可以在这个台上右键 → 直播源管理 → 「测试选中」，看看哪条还能用。

4) 画面卡顿 / 花屏
   → 在源管理里把可用的源「⤒ 置顶」；也可以换个来源同步一次
     （不同来源的线路和画质不一样）。

5) 同步时提示"没有匹配的来源"
   → 弹窗里默认不勾任何来源，需要你自己勾选。

6) 想恢复成出厂的频道表
   → 关掉程序，删掉 data\ 文件夹（或只删 data\liuhaitv.db），重新启动。

九、已知限制
------------
- 播放一个频道时最多只会尝试前 3 条源（首发 1 条 + 失败后切 2 条）。
  所以「源管理」里排在第 4 条之后的源不会被动用到 —— 把最可能好用的往前放。
- 公开清单里的地址会不定期失效，一个台全是红的通常不是程序问题，
  换一批地址即可。
- 部分地址来自境外服务器，网络环境不同可用性差别很大。
